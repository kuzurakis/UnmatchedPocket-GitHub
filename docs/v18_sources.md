# Источники версии 0.18

Данные сверялись 29 октября 2026 года. Короткие описания на четырёх языках пересказывают правила; сканы карт — английские.

- [Сорвиголова: данные колоды](https://unmatched.cards/api/db/decks/daredevil), [страница героя и изображения](https://www.the-unmatched.club/heroes/daredevil).
- [Меченый: данные колоды](https://unmatched.cards/api/db/decks/bullseye), [страница героя](https://www.the-unmatched.club/heroes/bullseye).
- [Электра: данные колоды](https://unmatched.cards/api/db/decks/elektra), [страница героя](https://www.the-unmatched.club/heroes/elektra).
- [Люк Кейдж: данные колоды](https://unmatched.cards/api/db/decks/luke-cage), [страница героя](https://www.the-unmatched.club/heroes/luke-cage).
- [Поле Адская кухня](https://www.the-unmatched.club/maps/hells-kitchen), [Рафт](https://www.the-unmatched.club/maps/the-raft): изображение, координаты, зоны, граф и старты.
- [Restoration Games: Redemption Row](https://restorationgames.com/shop/marvel-redemption-row/): состав и особенности набора.
- [Правила Redemption Row у издателя ALBI](https://albi.cz/data/files/products/50931/1669299734-unmatched-marvel-redemptionrowrules.pdf).

У Сорвиголовы колода 22 карты, у Электры 20; размеры не дополнялись до 30. Дополнительная сторона Электры не является вторым независимым героем. Возвращается сброс, а не рука; карты добавляются в оставшуюся колоду. Сила Сорвиголовы проверяет руку после розыгрыша карты. Дальность Меченого считается по связям без учёта занятости клеток, в дополнение к обычной дальней атаке по зоне. Защита Люка влияет на исход боя даже без карты, но не на Мисти и не на истощение.

Жетоны предметов в этой версии не реализованы: оба поля работают как обычные соревновательные арены. Это явно указано в игре. Набор Redemption Row заполнен пока частично.

Изображения не сгенерированы. URL и SHA-256 каждого скана, портрета и поля сохранены в манифестах data/card_images.json, data/avatars.json, data/boards.json. Никакие исходники старых карт и полей не заменялись.
