# Источники v0.17

Завершён The Witcher: Realms Fall: Эредин, Филиппа, общая колода Йеннифэр/Трисс и оба поля. Новая колода содержит 30 экземпляров, 11 типов карт; выбор главной героини не создаёт вторую колоду.

- [Официальные правила IELLO](https://iellogames.com/wp-content/uploads/2025/03/Unmatched_Witcher-Realms-fall_Set-rules_EN_V1.pdf).
- [Официальные правила Restoration Games](https://restorationgames.com/wp-content/uploads/2024/10/UM-W-RF-Set-Rules.pdf).
- [Оригинальные характеристики, карты и сканы](https://unmatched.cards/api/db/decks/yennefer-triss).
- [Изображения фишек](https://www.the-unmatched.club/heroes/yennefer-triss).

Перед игрой выбирается главная героиня с 14 ОЗ, другая получает роль помощницы с 6 ОЗ. Обе дальнобойные, движение 2. Именные карты следуют личности бойца. У ботов роль выбирается отдельно; сохранения хранят выбор. В меню используется один профиль общей колоды, поэтому обе версии не предлагаются как две отдельные колоды.

Йеннифэр-героиня получает необязательное усиление своей атаки на этапе «Сразу». Способность сохраняется при отмене эффектов карты. При наличии эффекта карты «Сразу» игрок выбирает порядок. Помощница Йеннифэр эту способность не использует.

После приёма самой Трисс-героини разрешается обязательный урон соседнему бойцу, включая дружественного. Если приём сыграла помощница, способности нет. При отсутствии соседей урон не наносится.

«Советница короля»: обе свои фигуры восстанавливают 1 ОЗ, игрок берёт карту; постоянный эффект увеличивает значения BOOST во всех собственных зонах на 1. Напечатанное значение сохраняется отдельно. При снятии постоянного эффекта значения возвращаются без накопления бонуса. Атака помощницы тоже сохраняет приём до следующего хода.

«Ложа чародеек»: сначала фиксируются выборы без раскрытия чужих карт, затем все раскрываются вместе. Раскрытые карты остаются в руках. Сравнивается фактическое количество взятых карт, с учётом пустой колоды; все лидеры при ничьей получают соответствующий урон герою. Истощение разрешается отдельно.

«Испепеление»: добровольная оплата двумя картами, которую нельзя прекратить после первого сброса. «Телепатия»: отказ от оплаты отменяет карту соперника с учётом защиты от отмены. «Град Меригольд»: решение принимает пострадавший игрок; сброс из колоды не считается взятием карт и не вызывает истощение. «Портал куда угодно» позволяет выбрать любого из двух бойцов в бою и учитывает блокировки перемещения.

Русские, букмол и испанские тексты — переводы прототипа; сканы английские. Права на правила и изображения принадлежат правообладателям. Личный фанатский проект.
