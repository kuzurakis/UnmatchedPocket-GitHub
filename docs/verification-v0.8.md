# Проверка версии 0.8.0

Результаты получены на Windows, Godot 4.7.1. Проверки включают модель, реальные окна интерфейса, JSON-сохранение посреди выбора, целостность данных и переводы. Физический Android-телефон в этой сессии не использовался. Автоматические прогоны не доказывают все возможные сочетания карт.

## Составные эффекты

Все 284 варианта карт выполнены в автоматическом и ручном режимах: 568 отдельных запусков. При разрешении выбора выполняется JSON-сохранение/загрузка; проверяется выход в устойчивое состояние. Отдельные проверки результата охватывают «Золотой рог» (добор + движение + лечение), «Камни в брюхе» (сброс + прибавка BOOST), «Какие у тебя большие глаза» (отмена + игнорирование силы), «Подготовить сцену» (добор + верх колоды), «А теперь следующий фокус» (движение + добор + действие), «Ловкость рук» (возврат старой карты + все эффекты замены), «Великое раскрытие» (оба усиления + оба бонуса + возврат одной карты), оплату Джинна (два сброса + действие/урон), отмену неполной оплаты, разные источники ярости и воскрешение Гудини/Бесс после смертельного урона.

Прежние серии повторены для базовых героев, InGen/рапторов, Али, «Тумана над мостовой» и «Баффи». Проверки просмотра руки и ловушек Малдуна остаются зелёными. Выборы id/indices после JSON восстанавливаются целыми числами. Сохранения форматов 1–8 поддерживаются.

## Данные и интерфейс

Аудит данных: 8416 проверок, 0 ошибок; 22 героя, 8 наборов, 13 полей, 284 скана, 39 записей портретов. Все 278 прежних изображений и прежние определения/переводы сохранены. По 1194 ключа на английском, норвежском и испанском, 1094 исходных строки покрыты.

Проверено открытие карточки каждого из четырёх игроков через реальный сигнал боковой плашки на четырёх языках, полный текст способности, портрет, текущее здоровье, состояние и доступ к сбросу. Просмотр не меняет состояние матча. Геометрия проверяется при 1280×720, 1600×720, 1280×800, 960×540 и 1024×768, включая четыре новых героя, двери во время манёвра и окна информации.

Источники и графы: [v08_sources.md](v08_sources.md). Новые тесты: `tests/v8_engine_tests.gd`, `tests/v8_ui_tests.gd`. Изображения тестовых экранов входят в исходный ZIP. Свежие APK/EXE проверяются отдельно по манифесту, подписи, содержимому и запуску Windows.
