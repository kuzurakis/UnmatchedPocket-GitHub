## Сверка с печатными картами

Текстовые поля каталога содержат ошибки. Они исправлены в данных приложения по сканам, исходные ответы каталога при исследовании сохранены отдельно.

- [A Momentary Glance](https://static.unmatched.cards/images/umdb/decks/titania/a-momentary-glance.png): урон 2 любому бойцу в зоне Титании. Посторонний текст каталога о Медузе и зеркалах не используется; у схемы нет боевого значения.
- [Maddening Insight](https://static.unmatched.cards/images/umdb/decks/hamlet/maddening-insight.png): значение по руке разрешается в бою; сброс при победе — после боя.
- [Outrageous Fortune](https://static.unmatched.cards/images/umdb/decks/hamlet/outrageous-fortune.png): сброс верхней карты и усиление происходят в бою, возврат при поражении — после боя.
- [Deceive](https://static.unmatched.cards/images/umdb/decks/william-shakespeare/deceive.png): отмена является немедленным эффектом; возврат самой карты — отдельным эффектом завершения строки.

Слоги берутся из печатных английских названий и не пересчитываются при переводе. Ингредиенты — по символам оригинальных карт. Русский, букмол и испанский тексты — переводы прототипа. Все старые герои, поля, изображения и переводы 0.12 сохранены.

Права на правила и изображения принадлежат правообладателям. Фанатский прототип для личного использования.
