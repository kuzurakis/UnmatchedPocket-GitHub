# Источники v0.12

Новый набор: Sun’s Origin / «Восход солнца» (2024), Ода Нобунага и Томоэ Годзэн, поле «Замок Адзути». Поле на двух игроков, 31 клетка, без специальных правил. Данные прежних героев, полей и изображений сохранены без изменений.

- [Официальные правила Sun’s Origin, IELLO](https://iellogames.com/wp-content/uploads/2024/02/Unmatched_Suns-Origin_Rulebook_EN_V1_Light.pdf).
- [Официальные правила набора, Restoration Games](https://restorationgames.com/wp-content/uploads/2024/01/UM-SO-Set-Rules.pdf).
- [Каталог оригинальных карт Оды](https://unmatched.cards/api/db/decks/oda-nobunaga), [Томоэ](https://unmatched.cards/api/db/decks/tomoe-gozen). Значения, количество экземпляров и английский текст сверены с каталогом; русский, букмол и испанский тексты — переводы прототипа.
- [Замок Адзути: изображение, клетки, связи и зоны](https://www.the-unmatched.club/maps/azuchi-castle).
- [Портреты Оды и Почётной стражи](https://www.the-unmatched.club/heroes/oda-nobunaga), [Томоэ](https://www.the-unmatched.club/heroes/tomoe-gozen).
- [Карты Золотого Бэта](https://unmatched.cards/umdb/decks/golden-bat): Terrifying Roar запрещает бойцам покидать клетки до конца текущего хода. Это не запрет на следующий ход; отмена эффектов карты предотвращает запрет.
- [Карты Шерлока Холмса](https://unmatched.cards/umdb/decks/sherlock-holmes): Elementary играется открыто, предсказывается напечатанное значение ещё закрытой атаки. Это карта Холмса, не Ватсона.

Окружение Оды требует двух бойцов под одним управлением. Союзник по команде не дополняет окружение, но получает зональный бонус Нобунаги к сыгранной боевой карте. Сам Нобунага свой бонус не получает. Томоэ наносит урон за каждый выход вражеского героя из её зоны, включая эффекты размещения и уход за поле; её собственное движение не наносит такой урон. Для выбора маршрута вражеские герои двигаются пошагово, пока жива Томоэ.

Права на изображения и правила принадлежат правообладателям. Фанатский прототип для личного использования.
