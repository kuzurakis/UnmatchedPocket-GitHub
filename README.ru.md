# Карманная арена / UnmatchedPocket

[English instructions](README.md) · [Файлы для скачивания](https://github.com/kuzurakis/unmatched-pocket/releases/tag/v0.38)

«Карманная арена» — неофициальная офлайн-игра по Unmatched. В версии 0.38 доступны 84 бойца, 34 поля, игра против ботов и интерфейс на русском, английском, норвежском букмоле и испанском.

## Установка и игра

1. Откройте [релиз v0.38](https://github.com/kuzurakis/unmatched-pocket/releases/tag/v0.38).
2. Для Android скачайте `UnmatchedPocket-v0.38-android.apk` и откройте его на телефоне. Если система спросит, разрешите установку APK тому приложению, из которого открыли файл. Сборка предназначена для телефонов с ARM и подписана отладочным ключом.
3. Для Windows x64 скачайте и запустите `UnmatchedPocket-v0.38-windows.exe`. Godot понадобится, если вы захотите запустить исходный проект или собрать его самостоятельно.
4. Начните новую игру, выберите бойца, поле и навык ботов. Нажмите на бойца или карту, чтобы прочитать описание.

## Проверка и самостоятельная сборка

Проект Godot находится в корне репозитория. В `scripts/` лежит код на GDScript, в `data/` — колоды, определения полей и переводы, в `assets/` — изображения игры. Проверку кода можно начать с `project.godot`, `main.tscn` и `scripts/game_engine.gd`. Скрипты сборки находятся в `tools/`, тесты — в `tests/`.

Импортируйте `project.godot` в Godot 4.7.1 с рендерером Compatibility и нажмите **F5**. Для экспорта установите шаблоны Godot той же версии. Для Android также нужны JDK 17 и Android SDK. Скрипты PowerShell принимают пути к этим инструментам. [Инструкция по сборке](README_BUILD.md)

Скачайте `UnmatchedPocket-v0.38-SHA256.txt` из того же релиза. Вычислите хеш файла и сравните его со строкой, в которой указано это имя файла.

```powershell
Get-FileHash -Algorithm SHA256 .\UnmatchedPocket-v0.38-android.apk
Get-FileHash -Algorithm SHA256 .\UnmatchedPocket-v0.38-windows.exe
```

Контрольная сумма позволяет сверить скачанный файл с опубликованным. Для независимой проверки можно изучить исходники по тегу релиза и собрать приложение со своим ключом. [Отчёт о тестах](docs/build-v0.38.md)
